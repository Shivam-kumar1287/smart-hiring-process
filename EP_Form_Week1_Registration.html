3. Formal Project Synopsis (Proposal)

3.1 Problem Definition

Modern hiring processes suffer from significant inefficiencies. Recruiters spend only 6 to 10 seconds reviewing a resume initially, leading to human error and qualified candidates being overlooked. Furthermore, candidates are frequently left without updates on their application status, and recruitment data remains fragmented across email inboxes and spreadsheets.

3.2 Solution & Objectives

The Smart Job Tracker resolves these issues by centralizing recruitment operations and automating screening using NLP.

  • Automate Candidate Screening: Process resume PDFs using Groq Cloud AI and calculate a matching score based on job description context.
  • Consolidate Hiring Pipeline: Establish a unified interface for HR to post jobs, update rounds, and track applications.
  • Robust Anti-Cheating Assessment: Assess coding abilities using a sandboxed browser IDE, tracking unauthorized tab switches automatically.
  • Direct Interview Integration: Host video calls directly within the app using WebRTC instead of third-party platforms.

3.3 Architecture & Implementation Details

The architecture utilizes a three-tier system layout:

  1. Client Tier (React 19): Reusable UI elements, state management via React Hooks, routing using react-router-dom, and Tailwind CSS 4 styling.
  2. Application Server (Express.js & Node.js): Defines REST routes mapping user requests to controllers. Employs middleware for verifying JWT tokens and evaluating roles.
  3. Database Tier (MongoDB Atlas): Stores data documents representing users, job posts, applications, meeting signaling states, and test submissions.

3.4 Proposed 20-Week Development Roadmap

  • Weeks 1–4: Project registration, initial requirement mapping, database schema design, and local project environment setup.
  • Weeks 5–8: Development of authentication flow (JWT signup/signin with verification OTP), profile management, and job CRUD interfaces.
  • Weeks 9–12: Integrating PDF text extractor and Groq AI Llama 3.3 service to fetch ATS scores and keyword reviews.
  • Weeks 13–16: Designing test assessment compiler, Monaco editor implementation, tab-switch tracking, and WebRTC meeting rooms.
  • Weeks 17–20: End-to-end integration, automated PDF offer letter module, Jest test suite execution, bug fixes, deployment, and documentation compilation.
